Quick Setup
1
Open Alexa Developer Console → Create skill → Custom + Alexa-hosted (Node.js)
2
Set invocation name to slyder swear jar (unique — avoids conflict with other "Swear Jar" skills)
3
Paste interaction-model.json into JSON Editor → Build Model
4
Paste index.js into Code tab → Deploy
5
⚠️ Your Alexa device must be signed into the same Amazon account as the Developer Console — dev skills only work for the dev account
6
Copy Skill ID from the URL → paste above → Save Settings
